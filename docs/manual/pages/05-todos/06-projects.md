A **project** is any outcome that needs more than one action, such as "Launch the holiday gift box line".

{{shot:todos-projects}}

## The Projects tab

The buttons at the top pick which projects you see: **Active**, **Someday**, **Completed** or **Dropped**. Each project card shows its status and how many open items it has. **Complete** marks it finished.

Use **Search projects…** to narrow the list, and **Views** to save a search for the team.

## Making a project

- Press **New project**, give it a name (the outcome you want) and optional notes.
- Or type `#Name` in the quick add box. A project with that name is created if it does not exist.
- Or pick **+ New project…** while sorting an inbox item.

## A project's page

Click a project to open it. Its todos are grouped into **Inbox**, **Next actions**, **Waiting / Delegated**, **Someday** and **Finished**. Type into **Add a next action…** to add one straight to the project.

You can edit the project in place:

- Click its **name** to rename it. Enter or clicking away saves. A blank name, or one another project already uses, is refused.
- Click its notes (**Add notes…** when empty) to edit them. Enter adds a new line; clicking away saves.
- **Purpose** (why the project exists) and **Outcome** (what done looks like) are one line each.
- Escape cancels an edit.
- **Project status** changes its status.

The ‹ › buttons beside "All projects" step to the previous or next project with the same status. The left and right arrow keys do the same when you are not typing.

## Keep projects moving

Every active project should have at least one next action. The [Review](08-done-and-review.md) tab lists active projects that have none.

Deleting a project does not delete its todos. They stay, just without a project.
