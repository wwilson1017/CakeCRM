The **To Do** tab lists every next action. The heading shows how many there are.

{{shot:todos-next}}

## Grouped by context

Starred next actions are pinned at the top. The rest are grouped under their context, such as **@calls** or **@computer**. Todos with no context sit under **No context** at the end. At your desk, work down @computer. With a few minutes and a phone, work @calls.

## Adding

- **Add next action** creates a todo directly in this list.
- The **Add to inbox** box above still adds to the inbox.

## Working the list

- Tick a todo to mark it done. **Undo?** stays available for seven seconds.
- Click the star to make it one of today's priorities.
- Click the title to edit it: status, context, project, dates, repeat, tags and notes.

## Filtering

Type in **Filter…** to narrow the list, and use **Filters** to pick a context.

## Renaming a context

Press **Rename** beside a context heading to rename it on every todo at once, finished ones included. If the context you want has no heading here, pick it in the context filter and **Rename** appears beside the filter.

If the new name already exists, nothing changes yet. The form offers **Merge**, which folds one context into the other. Merged todos cannot be told apart afterwards, so only merge when you mean it.

Renaming does not count as editing the todos, so the weekly review's stale list is unaffected.

## Good next actions

Write each next action as a physical, visible step. "Call Maria to confirm the order" beats "Maria".
