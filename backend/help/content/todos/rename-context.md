## Renaming a context everywhere

A context is plain text on each todo, so a typo or a change of habit can leave two
half-filled groups, such as `@phone` and `@calls`. Rename fixes that in one move.

Use **Rename** beside a context's heading on the **To Do** list or the **Contexts** tab. If
the context you want has no heading there, pick it in the context filter and the Rename link
appears beside the filter. That covers a context that only finished todos still carry.

Every todo carrying exactly that name changes, finished ones included. None of them counts
as freshly edited, so the weekly review's stale list and Waiting's ages stay as they were.

## When the new name already exists

If you rename `@phone` to `@calls` and `@calls` is already a context, nothing changes yet. The
form says so and offers **Merge**. Merging folds every `@phone` todo into `@calls`, and the
two cannot be told apart afterwards, so only merge when you mean it.

Renaming is not offered on the no-login todo link.
