## Importing a list

There is no import screen. The assistant does the import for you.

1. Export your list from the other app, as a CSV, JSON, text or Markdown file. A pasted list
   or a meeting's action items work too.
2. Open the assistant, attach the file with the **Attach a file** button (or paste the list),
   and ask it to bring the items in.
3. The assistant reads the list and matches items to the projects and contexts you already
   have. Anything it cannot place goes to your inbox as written.
4. It tells you the plan, then asks to create everything in one step. One **Approve** card
   lists every item. Long lists show the first twenty, with **Show all** for the rest.
5. Approve, and every item is created at once. Decline, and nothing is.

## Good to know

- One step holds up to 500 items. A longer list is split into several steps, each with its
  own card.
- It is all or nothing. If one item cannot be saved, nothing in that step is created, and
  the assistant fixes the item and asks again.
- Finished items from the old app come in as done, and a repeating one does not start a
  new copy.
- The assistant reads the first 50,000 characters of an attached file. Split a bigger
  export into parts.
- Importing needs an AI provider connected. Without one, add todos by hand.
