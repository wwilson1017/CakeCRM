## What you can set

Two things: your **company name** and a **logo**. Both are admin-only, in Settings,
Workspace, Branding.

## The logo

- Accepted formats: **PNG, JPEG, GIF and WebP**.
- SVG is deliberately refused. Browsers would not render it the way it is served here, and
  serving raw SVG from an address that needs no sign-in would be a security hole.
- Maximum size: **2 MB**. A larger file is rejected with a message, not silently resized.

Remove the logo from the same card and the wordmark stands alone.

## There is no colour picker

The theme is fixed: one considered look, in light and dark. There was an accent-colour
setting in an earlier version and it was removed — a stale value left over from then is
ignored. Nothing in the interface sets a custom brand colour, so if someone asks how to
change the accent, the honest answer is that this product does not offer it.

## Light and dark

Light and dark mode is a **personal** choice, not a branding setting. It is a toggle in the
app chrome, remembered in that browser, and it applies to every screen including the login
page and the assistant.
