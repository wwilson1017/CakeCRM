## Install CakeCRM

Everyone can open **Settings → Personal → Install on your phone**. On a computer the
card shows this site's address: open it on your phone and sign in first. The steps for your
current device start open; expand another device's steps whenever you need them.

If the browser offers installation, the card shows **Install CakeCRM**. Press it to open
the browser's install prompt. Otherwise follow the steps below.

## iPhone or iPad (Safari)

1. Tap **Share**, the square with an upward arrow. If it is hidden, tap **•••** first.
2. Scroll down and tap **Add to Home Screen**.
3. Leave **Open as Web App** on if shown, then tap **Add**.

## Android (Chrome)

1. Tap **⋮** at the right of the address bar.
2. Tap **Install and create shortcut**. Older Chrome calls it **Add to Home screen** or **Install app**.
3. Tap **Install**.

## Computer (Chrome or Edge)

1. Click the install icon at the right end of the address bar.
2. Click **Install**.

From then on, open CakeCRM from its home-screen icon. There is nothing to download from
an app store. When opened as an installed app, the card says you are already using it.

## Install the todo app separately

Under **Settings → Personal → Todo app devices**, make a sign-in code, open it on the
phone and press **Open my list on this device**. Then add that todo page to the home screen
using the same phone steps, also shown beneath the code. Its icon opens **Todos** at `/todo`.
See `todos/no-login-surfaces` for device sign-in and sign-out.

If installation is missing, check that you opened an **https://** address. On iPhone use
**Safari**, not an in-app browser.
